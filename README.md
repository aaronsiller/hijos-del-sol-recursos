# Hijos del Sol: recursos del juego publicado

Versión web 0.3.389. El código fuente y su historial se conservan en otro repositorio privado.

Contiene el juego exportado por fragmentos, mapas y capturas reales. Se mantiene la resolución de los mapas con compresión de alta calidad, transparencias, capas y navegación. `resources.json` incluye SHA-256.

Jugar: https://aaronsiller.itch.io/hijos-del-sol
